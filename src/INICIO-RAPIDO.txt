📋 ANTES DE EMPEZAR:
   
   ✅ Instalar Node.js → https://nodejs.org/ (versión LTS)
   ✅ Instalar Visual Studio Code → https://code.visualstudio.com/


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


📂 PASO 1: ORGANIZAR ARCHIVOS

   1. Crea una carpeta llamada: portafolio-jostin
   
   2. Dentro, crea esta estructura:
   
      portafolio-jostin/
      ├── public/          ← crear
      └── src/             ← crear
          ├── components/  ← crear
          │   ├── ui/      ← crear
          │   └── figma/   ← crear
          └── styles/      ← crear
   
   3. Mueve los archivos según MAPA-ORGANIZACION.md:
      
      ✂️ MOVER App.tsx → src/
      ✂️ MOVER carpeta components/ → src/components/
      ✂️ MOVER carpeta styles/ → src/styles/
      ✅ DEJAR archivos .json, .ts, .html en la raíz


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


💻 PASO 2: ABRIR EN VS CODE

   1. Abre Visual Studio Code
   
   2. Menú → Archivo → Abrir Carpeta
   
   3. Selecciona: portafolio-jostin
   
   4. Clic en "Sí, confío en los autores"


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


⚙️ PASO 3: INSTALAR DEPENDENCIAS

   1. En VS Code, presiona: Ctrl + Ñ  (abre la terminal)
   
   2. Copia y pega este comando:
   
      npm install
   
   3. Presiona ENTER y espera 2-3 minutos


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


🚀 PASO 4: EJECUTAR EL PROYECTO

   1. En la terminal, escribe:
   
      npm run dev
   
   2. Presiona ENTER
   
   3. Se abrirá automáticamente: http://localhost:5173
   
   🎉 ¡TU PORTAFOLIO ESTÁ FUNCIONANDO!


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


📸 PASO 5: AGREGAR TU FOTO

   1. Guarda tu foto en: public/perfil.jpg
   
   2. Abre: src/components/Hero.tsx
   
   3. En la línea 4, cambia:
      
      import profileImage from 'figma:asset/...';
      
      Por:
      
      import profileImage from '/perfil.jpg';
   
   4. Guarda (Ctrl + S) y recarga la página

🔧 COMANDOS ÚTILES:

   Iniciar servidor:          npm run dev
   Detener servidor:          Ctrl + C
   Compilar para producción:  npm run build
   Reinstalar dependencias:   npm install

❌ PROBLEMAS COMUNES:

   "npm no se reconoce"
   → Instala Node.js y reinicia tu computadora
   
   "Cannot find module"
   → Los archivos no están bien organizados, revisa MAPA-ORGANIZACION.md
   
   La página está en blanco
   → Presiona F12 en el navegador → pestaña Console → lee el error
   
   La foto no aparece
   → Lee ACTUALIZAR-FOTO.md
