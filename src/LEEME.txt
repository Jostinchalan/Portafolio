PASO 2: REQUISITOS PREVIOS
--------------------------------------------------------------------------------

Antes de empezar, necesitas instalar:

1. Node.js version 18 o superior
   Descargar: https://nodejs.org/
   Elige la version LTS (recomendada)

2. Visual Studio Code
   Descargar: https://code.visualstudio.com/

--------------------------------------------------------------------------------
PASO 3: ORGANIZACION RAPIDA
--------------------------------------------------------------------------------

Estructura que debes crear:

portafolio-jostin/
├── src/
│   ├── components/
│   │   ├── ui/         <-- ~49 archivos aqui
│   │   └── figma/
│   └── styles/
├── public/             <-- Tu foto aqui
└── documentacion/      <-- Archivos .md aqui

Archivos de configuracion (package.json, vite.config.ts, etc.) van en la raiz.

--------------------------------------------------------------------------------
PASO 4: INSTALACION
--------------------------------------------------------------------------------

Una vez organizados los archivos:

1. Abre la carpeta en Visual Studio Code
   Archivo > Abrir Carpeta > Selecciona 'portafolio-jostin'

2. Abre la terminal en VS Code
   Presiona: Ctrl + Ñ

3. Instala las dependencias:
   npm install

4. Ejecuta el proyecto:
   npm run dev

5. Abre el navegador en:
   http://localhost:5173

--------------------------------------------------------------------------------
